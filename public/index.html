Quick Setup

Install in 30 Seconds

Works on Google Chrome, Brave, Edge, and all Chromium browsers.

Option 1: Clone from GitHub & Build
git clone https://github.com/atharvgit2005/swayam404-knowledge.git
cd swayam404-knowledge
npm install && npm run build
Option 2: Load Unpacked in Browser
  1. Open Brave or Google Chrome.
  2. Navigate to chrome://extensions (or brave://extensions).
  3. Toggle on "Developer mode" in the top-right corner.
  4. Click "Load unpacked" (top-left button).
  5. Select the dist/ folder inside the project.
  6. Pin swayam404 to your browser toolbar! 📌

FAQ

Frequently Anticipated Panics

Do I need to buy an OpenAI API key or Google Cloud account? ▼
NO! Absolutely zero API keys are required. The extension uses your regular browser login for ChatGPT Web, Claude Web, or Gemini Web, plus the open-source GitHub question bank. It costs ₹0.00.
Why didn't the extension submit the quiz for me? ▼
Because we care about your graduation. Auto-submitting without student confirmation is how people accidentally submit empty forms or wrong answers. You have full control. Always verify before you submit.
Does this work on NPTEL and SWAYAM 2.0? ▼
Yes! It supports onlinecourses.swayam2.ac.in and standard NPTEL portal course containers.
Will SWAYAM detect that I'm using an extension? ▼
The extension runs standard client-side DOM queries (just like clicking with a mouse). It makes zero unauthorized background API requests to SWAYAM's servers and never harvests authentication cookies.
