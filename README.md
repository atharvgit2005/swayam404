# swayam404 — The SWAYAM Assignment Assistant Official Website

The official product landing page for **swayam404** (The SWAYAM Assignment Assistant Chrome Extension), matching the high-contrast **Neo-Brutalist Google Stitch design system** of the extension.

- **Live Production Website:** [https://swayam404.vercel.app](https://swayam404.vercel.app)

## ⚡ Superpowers & Features on the Website
* **Neo-Brutalist Google Stitch Design:** Authentic paper cream background (`#f5f0e8`) / obsidian dark mode (`#121214`), signature yellow container (`#ffcc00`), hard brutal shadows (`4px 4px 0px #1a1a1a`), and Space Grotesk / Inter typography.
* **Interactive In-Page Quiz Simulator:** Lets visitors try the extension directly on a simulated SWAYAM assignment: toggle between ChatGPT Web, Claude Web, and Gemini Web, click **"Copy Prompt"**, and click **"Fill Reviewed Answers"** to watch the DOM auto-marker in action.
* **The Canteen Rule & Caution Protocols:** The humorous guidelines from the README ("Bombastic Side Eye", "Don't flex 100/100 in the class WhatsApp group", "The 12% Attendance Law", "The Zero Auto-Submit safety guarantee").
* **Superpowers Breakdown:** Free Web AI Bridge (zero API costs), precision DOM marking with React synthetic event descriptors, GitHub knowledge bank sync, and feedback capture.
* **357 Automated Tests Badge:** Highlighting test coverage across 21 test suites.
* **30-Second Installation Walkthrough:** Instructions for Google Chrome, Brave, and Chromium browsers.
